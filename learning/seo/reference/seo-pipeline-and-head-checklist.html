Search Pipeline & Head-Tag Checklist

Reference · compressed from Lesson 1 · print-friendly

The pipeline (diagnose in this order)

StageQuestionDiagnostic toolCommon fixes
1 CrawlCan Google reach it?Search Console → URL Inspection; server logsInternal links, sitemap, unblock robots.txt, fix 5xx
2 IndexDid Google store it?site:domain; URL Inspection → coverageRemove stray noindex, fix canonicals, improve thin content
3 ServeWhy isn't it winning?Search Console → Performance (queries, impressions, position)Titles/descriptions matching search language, content depth, links, structured data

Exclusion mechanisms — don't mix these up

MechanismStops crawlingStops indexingUse for
robots.txtYesNo — linked URLs can still be indexedCrawl-traffic control (bulk, low-value paths)
<meta name="robots" content="noindex"> / X-Robots-TagNo (must stay crawlable to be seen)YesLogin, register, admin, profile pages
Omit from sitemapNoNoNothing — sitemap is a discovery hint, not exclusion

The <head> skeleton every indexable page needs

<title>Primary phrase in the searcher's words — Brand</title>
<meta name="description" content="150–160 chars: what the page does + why click.">
<link rel="canonical" href="https://domain.com/this-page">

<!-- localized sites: every version lists ALL versions + itself (bidirectional) -->
<link rel="alternate" hreflang="pt-BR" href="https://domain.com/pt/pagina">
<link rel="alternate" hreflang="en"    href="https://domain.com/en/page">
<link rel="alternate" hreflang="x-default" href="https://domain.com/en/page">

<!-- social preview (Open Graph) -->
<meta property="og:title" content="…">
<meta property="og:description" content="…">
<meta property="og:image" content="https://domain.com/og.png">

<!-- structured data: for a free web tool -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebApplication",
  "name": "MathFlow",
  "applicationCategory": "UtilitiesApplication",
  "operatingSystem": "Web",
  "offers": { "@type": "Offer", "price": "0" }
}
</script>

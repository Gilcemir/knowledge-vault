DFS Traversal — cheat sheet

Graphs track · reference · source lesson: L2

The template (adjacency list)

visited: set[int] = set()

def dfs(u: int) -> None:
    visited.add(u)              # mark ON ENTRY — before any neighbor
    for v in adj[u]:
        if v not in visited:
            dfs(v)

The template (grid / flood fill)

R, C = len(grid), len(grid[0])
visited: set[tuple[int, int]] = set()

def flood(r: int, c: int) -> None:
    visited.add((r, c))
    for dr, dc in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        nr, nc = r + dr, c + dc
        if (0 <= nr < R and 0 <= nc < C          # 1. exists?  (bounds — anatomy)
                and (nr, nc) not in visited      # 2. new?     (traversal)
                and grid[nr][nc] == grid[r][c]): # 3. allowed? (the problem's rule)
            flood(nr, nc)

Components

count = 0
for s in range(n):              # shared visited across launches
    if s not in visited:
        count += 1              # launches == connected components
        dfs(s)

Rules

RuleBreaking it costs
Mark on entry, never after the neighbor loopinfinite recursion — a late mark protects nothing while the cycle re-enters
Reachability marks are permanent — no un-markingun-marking = backtracking's question ("every path"), exponential or infinite here
Grid condition = three questions: exists / new / allowedfusing them (e.g. truthiness tests) welds the problem's rule into the anatomy
Bounds must reject negatives explicitly (0 <=)grid[-1] wraps silently — regions leak across the grid's edges

Glossary added by L2

cyclea path returning to its start without reusing an edge
reachablev is reachable from u if some chain of edges leads u → v
visitedthe traversal's memory: every vertex ever entered, permanent per run
connectedu, v connected ⇔ a path exists between them (undirected)
connected componenta maximal island of mutually connected vertices
flood fillone DFS launch on a grid, painting one same-label region

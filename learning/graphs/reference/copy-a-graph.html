The template (old → new map)

old_to_new: dict[Node, Node] = {}

def clone(u: Node) -> Node:
    if u in old_to_new:              # keys = the visited set...
        return old_to_new[u]         # ...values = the answer a set can't give
    copy = Node(u.val)
    old_to_new[u] = copy             # register BEFORE wiring — mark on entry
    for v in u.neighbors:
        copy.neighbors.append(clone(v))
    return copy

Rules that break if forgotten

  • Register before wiring. Map entry goes in the moment the clone exists, before the neighbor loop — else the cycle recurses forever (L2's mark-on-entry rule).
  • Never skip a seen neighbor. A traversal skips; a copy must still wire the edge — that's why the guard lives inside clone and returns the stored clone.
  • A visited set is not enough. It answers "seen?" but not "where is the clone?" — that retrieval is why the set upgrades to a dict.

Verifying a copy

copy1 = clone(n1)
assert copy1 is not n1                 # new object, not an alias
assert copy1.val == n1.val             # same label
assert copy1.neighbors[0] is not n2    # edges lead to clones, never originals

Cost

Time O(V + E): V node creations; 1 + 2E clone() calls (each undirected edge listed twice). Space O(V): the map + clones, plus O(V) worst-case recursion stack.

Stdlib equivalent

copy.deepcopy(obj) handles cycles by "keeping a memo dictionary of objects already copied during the current copying pass" (docs) — the memo dict is old_to_new. Use it in production; build it by hand on LC 133.

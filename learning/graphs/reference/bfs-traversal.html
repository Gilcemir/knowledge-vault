The queue: collections.deque

from collections import deque
q = deque([a, b])   # build, left to right           O(len)
q.append(x)         # join at the RIGHT, returns None O(1)
q.popleft()         # serve from the LEFT; IndexError if empty  O(1)
while q: ...        # empty deque is falsy

Never list.pop(0) as a queue — O(n) shift per pop turns O(V + E) into O(V²).

Template — reachability (distance order for free)

def bfs(adj: dict[int, list[int]], start: int) -> set[int]:
    seen: set[int] = {start}
    queue: deque[int] = deque([start])
    while queue:
        u = queue.popleft()
        for v in adj[u]:
            if v not in seen:
                seen.add(v)          # mark ON ENQUEUE — never on dequeue
                queue.append(v)
    return seen

Template — distances via the snapshot loop

def dist_from(adj: dict[int, list[int]], start: int) -> dict[int, int]:
    seen: set[int] = {start}
    queue: deque[int] = deque([start])
    dist: dict[int, int] = {}
    d = 0
    while queue:
        for _ in range(len(queue)):  # len evaluated ONCE -> exactly one layer
            u = queue.popleft()
            dist[u] = d
            for v in adj[u]:
                if v not in seen:
                    seen.add(v)
                    queue.append(v)
        d += 1
    return dist

Multi-source — the only change is the seed

queue = deque(sources)   # crowd at distance 0
seen = set(sources)

Rules that keep it correct

  • Mark on enqueue. Mark-on-dequeue lets a waiting vertex be enqueued again; the queue swells toward 2E. Same disease as L2's mark-after-loop and L3's register-after-wiring: claim before others can re-claim.
  • Layers = distances because (1) serving layer d only discovers vertices at ≤ d + 1, and (2) FIFO serves in arrival order — the queue never holds more than two consecutive layers. First arrival = shortest path.
  • Grid BFS = same template; the queue holds (r, c) tuples, neighbors come from the L2 three-question guard (exists? new? allowed?).

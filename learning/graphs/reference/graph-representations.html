Graph Representations — Cheat Sheet

Graphs track reference · source lesson: L1 — Graph Anatomy · grounded in Erickson ch. 5, §5.4

Adjacency list (the default)

adj: dict[int, list[int]] = {v: [] for v in range(n)}   # 1. EVERY vertex gets a key
for u, v in edges:                                      # 2. file each edge
    adj[u].append(v)
    adj[v].append(u)          # undirected only — drop this line if directed
  • Step 1 before step 2 — isolated vertices must exist as keys, or component counts and visits go wrong later.
  • Directed vs undirected is exactly one line: the reverse append.

Grid as implicit graph (no construction at all)

DIRS: tuple[tuple[int, int], ...] = ((-1, 0), (1, 0), (0, -1), (0, 1))  # U D L R

for dr, dc in DIRS:
    nr, nc = r + dr, c + dc
    if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
        ...  # (nr, nc) is a real neighbor
  • Rows bounded by len(grid), cols by len(grid[0]) — non-square grids punish swapping them.
  • grid[-1] wraps in Python, it never raises — the 0 <= half of the check is not optional.
  • Corners have 2 neighbors, edges 3, interior 4.

Cost table

Adjacency listAdjacency matrix
SpaceO(V + E)O(V²)
"Is (u, v) an edge?"O(deg(u))O(1)
Visit u's neighborsO(deg(u))O(V)
BuildO(V + E)O(V²)

Rule of thumb: traversals ask "visit my neighbors" constantly → list wins. Matrix is defensible only for small, dense graphs or edge-existence-heavy workloads. Sparse (E ≪ V²) + matrix = the wrong call.

Mini-glossary

grapha set of vertices plus the edges connecting them — dots and lines
vertex / node (V)a point in the graph; V = how many there are; grids: one cell = one vertex
edge (E)a connection between two vertices; E = how many there are
undirected / directededges work both ways (friendship) / one-way arrows (Twitter follow)
neighbors of uthe vertices sharing an edge with u
deg(u)number of neighbors of u
traversalan algorithm that walks the graph vertex by vertex, following edges (DFS, BFS)
sparse / denseE far below V² / E near V²
implicit graphneighbors computed by a rule, never stored (grids, word ladders)
isolated vertexvertex with no edges — must still exist in the representation

Topological Sort — cheat sheet

Graphs track · reference · source lesson: L6

Definition

A topological order lists every vertex exactly once so that for every edge u→v, u comes before v. It exists iff the graph is a DAG (no directed cycle), per Sedgewick & Wayne §4.2. It's usually not unique.

Checking an order: every arrow points right

Lay the order out as a line and draw each edge on it. The order is topological iff no arrow points left. In-degrees can't decide this: they count arrows into a vertex but don't say where those arrows start. Below, 1 and 2 both have in-degree 1, yet only the edge says which one goes first.

edges [0,1] [1,2], order [0, 2, 1]

     ┌─────────────┐      0→1 points right ✓
     │             ▼
    [0]    [2]    [1]
            ▲      │
            └──────┘      1→2 points LEFT ✗  → not topological
def is_topological(n: int, edges: list[list[int]], order: list[int]) -> bool:
    if sorted(order) != list(range(n)):   # each vertex exactly once; a set would hide [0, 0, 1]
        return False
    pos: dict[int, int] = {v: i for i, v in enumerate(order)}   # vertex -> position
    return all(pos[u] < pos[v] for u, v in edges)              # every arrow points right

Cost: O(V log V) for the sort, then O(V) to build pos and O(E) for the edge check. Added after the L6 drill hand-in (2026-11-05).

Kahn's loop (queue-based)

adj: list[list[int]] = [[] for _ in range(n)]
indeg: list[int] = [0] * n
for u, v in edges:              # u -> v, DIRECTED: one entry only
    adj[u].append(v)
    indeg[v] += 1

q: deque[int] = deque(v for v in range(n) if indeg[v] == 0)
order: list[int] = []
while q:
    u = q.popleft()
    order.append(u)
    for v in adj[u]:
        indeg[v] -= 1           # one requirement met
        if indeg[v] == 0:       # the LAST one: v is ready
            q.append(v)

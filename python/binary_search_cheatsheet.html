Binary Search

Cheat Sheet completo — invariantes, ponteiros e o porquê de cada decisão

1

Exact Match

Busca exata
💬 "O valor target existe no array? Se sim, em qual índice?"
< target
== target
> target
def exact_match(arr, target):
    lo, hi = 0, len(arr) - 1

    while lo <= hi:          # ← inclui lo == hi (1 elemento)
        mid = lo + (hi - lo) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1

    return -1               # não encontrado
CondiçãoMovimentoPor quê
arr[mid] == targetretorna midAchou!
arr[mid] < targetlo = mid + 1mid e tudo à esquerda são menores — descarta
arr[mid] > targethi = mid - 1mid e tudo à direita são maiores — descarta
⚠️ Loop condition
lo <= hi — porque com um único elemento (lo == hi) ainda pode ser o target. Retorna -1 ao terminar pois o elemento não existe.
2

Lower Bound

1ª ocorrência / ≥ target
💬 "Qual o menor índice i tal que arr[i] >= target?"
False — arr[i] < target
True — arr[i] >= target

↑ queremos o primeiro True

def lower_bound(arr, target):
    lo, hi = 0, len(arr)  # hi = len (fora do array!)

    while lo < hi:           # ← lo == hi → convergiu
        mid = lo + (hi - lo) // 2

        if arr[mid] < target:
            lo = mid + 1       # mid é False, descarta
        else:
            hi = mid            # mid pode ser a resposta, guarda

    return lo               # lo == hi == resposta
CondiçãoMovimentoPor quê
arr[mid] < targetlo = mid + 1mid é definitivamente False — descarta
arr[mid] >= targethi = midmid pode ser a resposta — não descarta
⚠️ Detalhes críticos
hi = len(arr) cobre o caso "target maior que tudo" (retorna índice inexistente). hi = mid (não mid-1) porque mid pode ser o primeiro True. Ao fim, lo == hi é a resposta.
3

Upper Bound

Após última ocorrência / > target
💬 "Qual o menor índice i tal que arr[i] > target?"
False — arr[i] <= target
True — arr[i] > target

↑ queremos o primeiro True

def upper_bound(arr, target):
    lo, hi = 0, len(arr)

    while lo < hi:
        mid = lo + (hi - lo) // 2

        if arr[mid] <= target:   # única diferença vs lower_bound!
            lo = mid + 1
        else:
            hi = mid

    return lo
CondiçãoMovimentoPor quê
arr[mid] <= targetlo = mid + 1mid é False (inclui o igual!) — descarta
arr[mid] > targethi = midmid pode ser a resposta — não descarta
💡 Uso combinado com Lower Bound
[lower_bound(t), upper_bound(t)) → range de todas as ocorrências de t.
Contagem de ocorrências: upper_bound(t) - lower_bound(t)
4

Search on Answer

Espaço de respostas
💬 "Qual o menor valor x tal que f(x) é True?" — ex: Koko Eating Bananas
False — f(x) não satisfaz
True — f(x) satisfaz

↑ queremos a fronteira

def search_on_answer(lo, hi, f):
    # Invariante: resposta sempre em [lo, hi]
    while lo < hi:           # lo == hi → convergiu na fronteira
        mid = lo + (hi - lo) // 2

        if f(mid):
            hi = mid            # mid pode ser a resposta, guarda
        else:
            lo = mid + 1       # mid é False, descarta

    return lo               # lo == hi == menor x com f(x) True

# Koko: f(k) = "consigo comer tudo em h horas com velocidade k?"
CondiçãoMovimentoPor quê
f(mid) == Truehi = midmid satisfaz mas pode existir algo menor — guarda
f(mid) == Falselo = mid + 1mid definitivamente não serve — descarta
⚠️ Pré-condição obrigatória
f deve ser monotônica: uma vez que f(x) vira True, f(x+1) também é True. Sem isso, binary search não funciona aqui.
